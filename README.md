# dsh-agent-lab

期货主力连续合约 MACD 顶底背离识别工具。

## 常见问题

### 数据从哪里来？

本工具从新浪财经期货接口拉取主力连续合约的日线数据，无需额外 API Key，开箱即用。

### MACD 参数可以自定义吗？

目前使用默认参数 (12, 26, 9)。如需调整，可修改 `futures_divergence.py` 中 `calc_macd` 函数的 `fast`、`slow`、`signal` 参数。

### 支持哪些期货品种？

目前覆盖 20 个主力连续合约，包括螺纹钢、铁矿石、热卷、甲醇、PTA、聚丙烯、沪铜、沪铝、沪金、沪银、豆粕、豆油、棉花、白糖、原油、沪镍、沪锌、燃料油、沥青和菜粕。如需添加品种，可在 `futures_divergence.py` 的 `FUTURES_LIST` 列表中新增对应的合约代码和名称。

### 如何运行这个工具？

直接执行 `python3 futures_divergence.py` 即可。脚本仅依赖 Python 标准库，无需安装第三方包。运行后会依次拉取各品种日线数据并计算 MACD 背离，最终在终端输出 Markdown 格式的结果表格。

### 背离信号可以作为交易依据吗？

不可以直接作为交易依据。MACD 背离仅是一种技术分析参考信号，存在滞后和误判的可能。建议结合成交量、持仓量、基本面等多维度信息综合判断，并做好风险管理。本工具仅供学习研究，不构成任何投资建议。
